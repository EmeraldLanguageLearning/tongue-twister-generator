# Tongue Twister Generator

An Emerald Language Learning tool for English pronunciation practice. Type a sound or a spelling (`th`, `ea`, `sh`, `/iː/`…) and it builds a tongue twister that drills it, with:

- a word-by-word IPA transcription (modern Standard Southern British English), with the target sound highlighted;
- an optional contrast sound (for example /θ/ against /s/) to practise minimal pairs;
- short, medium or long twisters;
- an articulation tip for each sound, in French or English;
- listening at three speeds (the device's English voice);
- a practice set you can print or save as PDF, or export to Anki.

Everything runs in the browser from the single file `index.html`: no server, no account, nothing sent anywhere. The practice set is kept in the browser's local storage.

It is also part of the Emerald Tools website ([Emerald-web](https://github.com/EmeraldLanguageLearning/Emerald-web)) as `tongue-twisters.html`.

## Use it

Open `index.html` in a browser. To publish it on its own, turn on GitHub Pages for this repository (Settings → Pages → Deploy from a branch → `main`, root).
